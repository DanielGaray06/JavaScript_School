Información del proyecto

Cómo está construido

Un proyecto académico sin frameworks de interfaz: HTML semántico, Tailwind CSS compilado localmente y módulos ES6 con separación estricta entre lógica, validación y presentación.

Stack y decisiones

  • HTML5 semántico y ARIA para navegación por teclado y lectores de pantalla.
  • Tailwind CSS 3.4 compilado con su CLI local (sin CDN) y CSS propio para el sistema visual.
  • JavaScript ES6+ con import/export, sin React, Vue ni Angular.
  • Cero dependencias de runtime: el navegador solo recibe HTML, CSS y JS.

Arquitectura

index.html
assets/
├─ css/styles.css   → fuente Tailwind
├─ css/build.css    → CSS compilado
├─ js/main.js       → arranque
├─ js/exercises/    → 8 lógica puras
├─ js/ui/           → DOM y código
└─ js/utils/        → validación

La lógica de cada ejercicio no toca el DOM. La UI la invoca y renderiza.

Ejecutar en local

pnpm install
pnpm dev

# http://localhost:5173

pnpm dev compila Tailwind en modo watch y levanta el servidor estático. Los módulos ES6 requieren HTTP, no file://.

  • ✓ Validaciones y estados de error accesibles
  • ✓ Loading real en ejercicios asíncronos
  • ✓ Responsive desde 320 px

¿Sin Node.js instalado?

Descárgalo desde nodejs.org (versión LTS). Luego instala pnpm con corepack enable y sigue el README.
